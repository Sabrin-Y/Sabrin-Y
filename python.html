01 · PANDAS DATA ANALYSIS

Student Dataset Analysis

Using student.csv, the exercises introduced the core Pandas workflow: loading a CSV file into a DataFrame, inspecting the data, selecting columns and rows, filtering records, transforming columns and calculating grouped statistics.

Load & Explore

Read the CSV file, display the first five rows, inspect the DataFrame and generate summary statistics. 

import pandas as pd

df = pd.read_csv("student.csv")

print(df.head())
df.info()
print(df.describe())

Indexing & Slicing

Selected individual columns, multiple columns, the first three rows and students in class Four. 

print(df["name"])
print(df[["name", "mark"]])
print(df.head(3))
print(df[df["class"] == "Four"])

Data Manipulation

Created a pass indicator, renamed a column and removed a column from the DataFrame. 

df["passed"] = df["mark"] >= 60

df.rename(
    columns={"mark": "score"},
    inplace=True
)

df.drop(columns=["passed"], inplace=True)

Aggregation & Grouping

Calculated mean scores by class and gender and counted the number of students in each class. 

df.groupby("class")["score"].mean()

df["class"].value_counts()

df.groupby("gender")["score"].mean()

Advanced Operations

Created a pivot table, generated grades from scores and sorted the DataFrame by score. 

df.pivot_table(
    values="score",
    index="class",
    columns="gender"
)

df.sort_values(
    by="score",
    ascending=False
)

Exporting Data

Saved the transformed DataFrame, including the new grade column, to a CSV file. 

df.to_csv(
    "student_with_grades.csv",
    index=False
)
