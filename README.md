# Sabrin Y — Data Technician Portfolio

Welcome to my data analytics portfolio.

This repository showcases practical projects completed as part of my Level 3 Data Technician training. The portfolio demonstrates how I have developed skills across data analysis, visualisation, business intelligence, database querying and Python-based data analysis.

## Portfolio Projects

### Excel
Practical Excel-based data analysis using formulas, data manipulation and visualisation to explore datasets and communicate findings.

### Tableau
Interactive data visualisation projects focused on presenting data clearly and identifying patterns and trends.

### Power BI
A Power BI dashboard project demonstrating data visualisation, dashboard design and the use of DAX to support analysis and reporting.

### SQL
Practical SQL work using MySQL Workbench and the `world_db` database. The project demonstrates relational database concepts, filtering, sorting, aggregation, pattern matching and JOINs.

### Python
Python and Pandas exercises covering data exploration, DataFrame manipulation, grouping and aggregation, GDP data analysis and data visualisation.
